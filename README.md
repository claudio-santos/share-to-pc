# ShareToPC

Send links from your Android phone and open them in the browser of your PC (Windows).

Two components:

- [`share-to-pc-app/`](share-to-pc-app/README.md) — Android app (Kotlin + Compose) that captures the share intent.
- [`share-to-pc-server/`](share-to-pc-server/README.md) — Go webserver that receives the URLs and opens them in the browser.

Build, run and usage instructions are in each component's README.
